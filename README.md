# 🌌 Aurora OS

> **The Next Generation Virtualization Platform**

Aurora OS ist eine moderne Virtualisierungs- und Servermanagement-Plattform, die sich an Proxmox orientiert, jedoch mit einem modernen Design, erweiterten Funktionen und einer deutlich einfacheren Bedienung.

Das Ziel von Aurora OS ist es, Serververwaltung, Virtualisierung und Game-Hosting in einer einzigen Plattform zu vereinen.

# ⚙️ Installation

Repository klonen

```bash
git clone https://github.com/Ricko124/aurora-os.git
```

Projekt öffnen

```bash
cd aurora-os
```

Python-Abhängigkeiten installieren

```bash
pip install -r requirements.txt
```

Server starten

```bash
uvicorn app:app --reload
```

Danach ist Aurora OS erreichbar unter

```
http://127.0.0.1:8000
```
